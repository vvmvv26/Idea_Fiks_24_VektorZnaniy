# Вектор Знаний

Чат-бот для мессенджера МАКС: персональный ИИ-ассистент для учёбы, умный поиск по материалам, автопроверка заданий и генерация тестов — для учителя и ученика в одном входе. Проект команды «Вектор 26» (Ставрополь) на хакатон «Идея фикс», трек 4 «Портал в будущее» — «Искусственный интеллект в школьных процессах».

Бот в МАКС: https://max.ru/ideya_fiks_24_bot

> **Нейросеть на сервере проверки.** Бот отвечает с помощью локальной нейросети Qwen 2.5 через Ollama — без платных API и без передачи данных во внешние сервисы. На сервере проверки (2 ядра, 4 ГБ памяти) работает модель `qwen2.5:3b-instruct`: ответ занимает около двух минут, запросы обрабатываются по очереди. На сервере с памятью меньше 3,5 ГБ скрипт установки сам выберет компактную модель `qwen2.5:1.5b-instruct`. Если нейросеть недоступна, бот продолжает работать: поиск по материалу, тест по своему конспекту и формальная проверка ответа выполняются в самом боте, остальные функции выдают готовый промт с кнопками бесплатных чатов.

## Какую проблему решаем

Учитель тратит много времени на подготовку уроков, проверочных и раздаточных материалов, ученику не хватает понятного объяснения «здесь и сейчас». Нейросети могут помочь, но без навыка составления запросов дают общие ответы, а платный доступ школе недоступен.

Опрос команды в Ставрополе: **72 учителя и 118 учеников 5–11 классов**.

| Что показал опрос | Доля |
|---|---|
| Учителя хотят автоматизировать подготовку материалов | 84% |
| Учителям не хватает индивидуализации заданий | 65% |
| Ученики хотят получать понятное объяснение сразу | 82% |

Пилот прежних ботов команды (SmartTeach для учителей, SmartStudent для учеников) — **24 педагога и 56 учеников 7–9 классов, всего 80 пользователей**:

| Метрика | До | С ботом |
|---|---|---|
| Подготовка урока | 42 мин | 18 мин (−57%) |
| Разбор задачи учеником | 15 мин | 8 мин (−47%) |
| Материалы прошли экспертную проверку на соответствие ФГОС | — | 94% |

«Вектор Знаний» объединяет оба бота в один вход с выбором роли и переносит их в МАКС, где уже общаются школы Сферума.

## Как бот закрывает задачи трека

| Задача трека | Функция бота | Без нейросети | С нейросетью |
|---|---|---|---|
| Персональный ИИ-ассистент для учёбы | **Спросить ассистента**: любой вопрос своими словами, ассистент помнит предыдущий вопрос | Промт с вопросом + кнопки бесплатных чатов | Ответ в чате, уточнения «Проще», «Подробнее», «Ещё пример» |
| | **Учебный материал**: 17 сценариев (9 для учителя, 8 для ученика) по 15 и 12 предметам — план урока, объяснение темы, разбор задачи, проверочная, конспект, план проекта и др. | Точный промт по ФГОС под класс, тему и предмет + кнопки бесплатных чатов | Готовый материал в чате и файлом Word |
| Умный поиск по учебным материалам | **Поиск по материалу**: файл .txt, .pdf, .docx или текст | Номер абзаца, цитата и степень совпадения | Плюс связный ответ по найденным абзацам |
| Автопроверка заданий и обратная связь | **Проверка ответа** по заданию или критериям | Объём, длина предложений, повторы, какие ключевые слова задания не раскрыты | Плюс разбор: что верно, ошибки, рекомендации |
| Генерация тестов и викторин | **Тест по своему материалу** | Тест с выбором ответа и ключом по тексту конспекта, со ссылкой на абзац | То же |
| | **Тест по теме** | Промт + кнопки чатов | Тест с ключом и напоминанием проверить ключ |

**Ответ здесь или промт для другой нейросети.** Когда пользователь ввёл данные, бот спрашивает, как получить результат:
- **🤖 Ответ здесь** — с примерным временем ожидания; готовый ответ можно скачать файлом Word, уточнить («Проще», «Подробнее», «Ещё пример») и оценить;
- **📋 Промт для другой нейросети** — готовый запрос и кнопки ChatGPT, GigaChat, YandexGPT, DeepSeek.

Найденные абзацы, быстрая проверка ответа и тест по своему материалу приходят сразу: нейросеть для них не нужна.

**Удобство.**
- В чате всегда одно активное меню, прежние меню убираются, поэтому ничего не путается.
- В заголовке меню видна текущая роль: «👩‍🏫 Учитель · Методист».
- Бот запоминает класс, и во втором сценарии его можно выбрать одной кнопкой.
- После отмены или ошибки появляются кнопки «Продолжить» и «Начать заново».

Тесты и ответы скачиваются **файлом Word**: эмблема и колонтитулы, тест оформлен как бланк для ученика, ключ ответов — на отдельной странице. Удачные промты сохраняются в **⭐ избранное**: там их можно открыть снова или удалить. Ещё в боте: готовые примеры, «Идея дня», справка.

## Как измеряем пользу

- Под каждым результатом кнопки **👍 Полезно / 👎 Не помогло**.
- Команда **/stats** показывает анонимные счётчики: сколько подготовлено материалов, проведено поисков, проверено ответов, составлено тестов, скачано файлов, и долю полезных ответов. Имена и идентификаторы пользователей не сохраняются.
- Целевые метрики, которые проверяем на пилоте в МАКС: время подготовки урока (было 42 → 18 мин), время разбора задачи (15 → 8 мин), доля ответов «👍» — не ниже 80%.
- После оценки «👍» бот предлагает поделиться ссылкой на себя с коллегами и одноклассниками.

## Архитектура

```
МАКС ⇄ maxapi (long polling) ⇄ vektor_znaniy_max_bot.py — сценарии диалога (FSM)
                                    ├─ prompts.py    библиотека промтов: данные, без логики
                                    ├─ texts.py      тексты сообщений
                                    ├─ keyboards.py  кнопки
                                    ├─ materials.py  файлы, абзацы, поиск, тест по материалу, быстрая проверка
                                    ├─ exporter.py   выгрузка в .docx: колонтитулы с эмблемой, бланк теста, ключ таблицей
                                    ├─ formatting.py Markdown и формулы нейросети → оформление МАКС
                                    └─ llm_client.py нейросеть по OpenAI-совместимому API (Ollama)
```

- **Новый сценарий без программирования.** Шаблон (название, текст промта, список полей) добавляется в `prompts.py` — кнопка, вопросы пользователю и сборка промта появляются автоматически. Новый предмет — одна строка там же.
- **Интеграции.**
  - МАКС — через `maxapi`.
  - Нейросеть — по OpenAI-совместимому API, адрес задаётся переменной `LLM_API_BASE`. Подходит любой такой сервер: Ollama, LM Studio, vLLM. Код при этом не меняется.
  - Бесплатные веб-чаты (ChatGPT, GigaChat, YandexGPT, DeepSeek) — кнопками.
  - Обмен файлами — .txt, .pdf, .docx на входе, .docx на выходе.
  - Docker-образ публикуется в GitHub Container Registry.
- **Стабильность.**
  - Каждое событие обрабатывается отдельной задачей: долгий ответ нейросети одному пользователю не задерживает других, а события одного пользователя идут по очереди.
  - Ошибка в сценарии не роняет бота: пользователь получает сообщение и кнопки «Продолжить» и «Начать заново».
  - Если нейросеть недоступна, бот сам переходит на выдачу промтов и раз в минуту проверяет, не вернулась ли она.
  - Точность: низкая «температура» генерации, правила «не выдумывай факты, если не уверен — скажи» в каждом запросе, ограничение длины ответа.
  - Контейнер перезапускается после сбоя и перезагрузки сервера, логи ограничены по размеру.
- **Проверка.** `bot/tests/smoke_test.py` — более 100 проверок всех сценариев через настоящий диспетчер maxapi, без сети и токена. Включая поведение API МАКС, на котором однажды ломались кнопки.

## Данные и 152-ФЗ

Базы данных нет. Роль, избранное и загруженный материал живут только в памяти текущей сессии: материал удаляется через 30 минут или по /start, всё остальное — по /start. Бот не спрашивает ФИО, оценки и другие персональные данные учеников. Подробнее — в `bot/README.md`.

## Быстрый старт

Нужен Python 3.11 или новее и токен бота из МАКС (диалог с @MasterBot, команда `/create`).

```bash
cd bot
python -m venv venv
```

```bash
venv/Scripts/pip install -r ../requirements.txt
```

На Linux и macOS вместо `venv/Scripts/` используйте `venv/bin/`.

Скопируйте `.env.example` в `.env`, впишите в `MAX_BOT_TOKEN` свой токен и запустите:

```bash
venv/Scripts/python vektor_znaniy_max_bot.py
```

Пример запуска из командной строки с токеном без файла `.env` (Linux/macOS):

```bash
cd bot
MAX_BOT_TOKEN=ваш_токен python vektor_znaniy_max_bot.py
```

В Windows PowerShell:

```powershell
cd bot
$env:MAX_BOT_TOKEN="ваш_токен"; python vektor_znaniy_max_bot.py
```

В логе появится строка о режиме работы: «без модели» (промты и кнопки бесплатных чатов) или «ответы локальной модели». Проверка сценариев без сети и токена: `python tests/smoke_test.py` из папки `bot`.

## Установка на сервер одной командой (Ubuntu 24.04)

На чистом сервере Ubuntu 24.04:

```bash
curl -fsSL https://raw.githubusercontent.com/vvmvv26/Idea_Fiks_24_VektorZnaniy/main/deploy.sh | sudo bash
```

Скрипт `deploy.sh` ставит Docker, скачивает проект в `/opt/vektor-znaniy`, спрашивает токен бота и нужна ли локальная нейросеть, собирает и запускает контейнеры. Бот сам поднимается после перезагрузки сервера. Обновление до последней версии из GitHub — `sudo vektor-update`, токен при этом сохраняется.

## Запуск в Docker

Нужен установленный Docker. Все команды выполняются из корня репозитория.

Сборка образа:

```bash
docker build -t vektor-znaniy-bot .
```

Запуск контейнера с токеном из командной строки:

```bash
docker run -d --name vektor-znaniy-bot --restart unless-stopped --log-opt max-size=10m -e MAX_BOT_TOKEN=ваш_токен vektor-znaniy-bot
```

Или с настройками из файла `bot/.env` (скопируйте его из `bot/.env.example` и впишите токен):

```bash
docker run -d --name vektor-znaniy-bot --restart unless-stopped --log-opt max-size=10m --env-file bot/.env vektor-znaniy-bot
```

Логи и остановка:

```bash
docker logs -f vektor-znaniy-bot
docker stop vektor-znaniy-bot
```

### Готовый образ из GitHub Container Registry

Образ собирается автоматически при каждом обновлении ветки `main` (GitHub Actions, `.github/workflows/docker-image.yml`). Собирать его самому не обязательно:

```bash
docker pull ghcr.io/vvmvv26/idea_fiks_24_vektorznaniy:latest
docker run -d --name vektor-znaniy-bot --restart unless-stopped --log-opt max-size=10m -e MAX_BOT_TOKEN=ваш_токен ghcr.io/vvmvv26/idea_fiks_24_vektorznaniy:latest
```

### Docker Compose: бот вместе с локальной моделью

Перед запуском создайте `bot/.env` из `bot/.env.example` и впишите токен: compose берёт настройки оттуда.

Только бот (без ИИ, промты и кнопки бесплатных чатов):

```bash
docker compose up -d --build
```

Бот и Ollama с моделью `qwen2.5:3b-instruct` (около 2 ГБ, скачивается один раз; на сервере с памятью меньше 3,5 ГБ используйте `qwen2.5:1.5b-instruct` и укажите её в `LLM_MODEL` в `bot/.env`):

```bash
docker compose --profile ai up -d --build
docker compose exec ollama ollama pull qwen2.5:3b-instruct
```

Модель скачивать не обязательно сразу: бот раз в минуту проверяет Ollama и сам включает ответы, как только модель появится. Остановка: `docker compose --profile ai down`.

Подробности про режимы работы, локальную модель и соответствие ФГОС и 152-ФЗ — в `bot/README.md`. Развёртывание на сервере — в `docs/deploy.html`.

## Важно про секреты

Файл `.env` с токеном в репозиторий не попадает (он в `.gitignore`). Не добавляйте токены в код и не коммитьте их.
