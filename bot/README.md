# Вектор Знаний — бот

Код чат-бота для мессенджера МАКС. Общее описание проекта, метрики, установка на сервер и запуск в Docker — в [README в корне репозитория](../README.md).

Бот написан на Python 3.11+ и библиотеке [maxapi](https://github.com/love-apples/maxapi) (асинхронный фреймворк для ботов МАКС в стиле aiogram): long polling, диалоги на `StatesGroup`/`State`, инлайн-кнопки.

## Функции

После `/start` пользователь выбирает, кто он (учитель или ученик), и роль ассистента (методист, конструктор уроков, тьютор, тренер к экзамену, помощник по проектам). Дальше — главное меню.

| Функция | Что делает | Без нейросети | С нейросетью |
|---|---|---|---|
| 💬 Спросить ассистента | Вопрос своими словами; ассистент помнит предыдущий вопрос | Промт с вопросом + кнопки бесплатных чатов | Выбор: ответ здесь или промт для другой нейросети |
| 📝 Учебный материал | 17 сценариев: 9 для учителя (план урока, проверочная, рабочий лист, критерии оценивания и др.), 8 для ученика (объяснение темы, разбор задачи, конспект, план проекта и др.) | Промт по ФГОС под класс, тему и предмет | Выбор: ответ здесь или промт |
| 🔎 Поиск по материалу | Файл .txt, .pdf, .docx или текст; вопрос по нему | Номер абзаца, цитата, степень совпадения | Плюс выбор: связный ответ здесь или промт |
| ✅ Проверка ответа | Ответ ученика по заданию или критериям | Объём, длина предложений, повторы, нераскрытые ключевые слова задания | Плюс выбор: разбор здесь или промт |
| 🧩 Тест по своему материалу | Тест с вариантами ответа по тексту конспекта | Тест и ключ со ссылками на абзацы, сразу | То же |
| 🧩 Тест по теме | Тест или открытые вопросы по любой теме | Промт + кнопки чатов | Выбор: тест здесь (с напоминанием проверить ключ) или промт |

**Порядок работы с нейросетью.** Когда данные собраны, бот предлагает «🤖 Ответ здесь» (с примерным временем ожидания) или «📋 Промт для другой нейросети». Под готовым ответом:
- «📄 Скачать файл Word»;
- «📋 Промт для другой нейросети»;
- уточнения «Проще», «Подробнее», «Ещё пример»;
- оценка 👍/👎.

Под промтом — кнопки бесплатных чатов, «⭐ В избранное» и «🤖 Ответ здесь». Если нейросеть недоступна, выбирать не из чего, и бот сразу присылает промт.

Ещё:
- 📚 примеры промтов (6 штук);
- ⭐ избранное: открыть промт снова или удалить, «Очистить всё»;
- 🎲 идея дня (12 идей для урока);
- анонимная статистика `/stats`.

Команды: `/start`, `/help` (или `/помощь`), `/info`, `/cancel`, `/stats`.

Интерфейс:
- В чате всегда одно активное меню: кнопки результата собраны в нём же, у прежних меню кнопки снимаются.
- В заголовке главного меню видна текущая роль.
- Класс запоминается и в следующем сценарии выбирается одной кнопкой.
- После отмены или ошибки — кнопки «Продолжить» и «Начать заново», вводить `/start` не нужно.

## Нейросеть

Бот обращается к локальной модели через [Ollama](https://ollama.com) по OpenAI-совместимому API. Запросы идут на сервер, где работает бот, во внешние сервисы ничего не передаётся. Других облачных провайдеров код не вызывает; кнопки ChatGPT, GigaChat, YandexGPT и DeepSeek — это просто ссылки на их бесплатные веб-чаты.

| Модель | Память сервера | Ответ на 2 ядрах |
|---|---|---|
| `qwen2.5:3b-instruct` | от 3,5 ГБ (модель занимает ~2,4 ГБ) | около 2 минут, заметно точнее; рекомендуется |
| `qwen2.5:1.5b-instruct` | меньше 3,5 ГБ | быстрее, но ответы проще и чаще с ошибками |

Скрипт `deploy.sh` сам выбирает модель по объёму памяти. Её можно поменять в `bot/.env` (`LLM_MODEL`).

Как бот держит качество ответов:
- низкая «температура» генерации и ограничение длины ответа;
- в каждый запрос добавляются правила: не выдумывать факты и формулы, если не уверен — сказать прямо;
- Markdown и формулы LaTeX из ответа модели переводятся в оформление МАКС (жирный текст, списки, √3/2, x², π/2);
- под тестом от нейросети — напоминание проверить ключ ответов.

Если модель недоступна или не ответила, бот не падает: присылает готовый промт с кнопками бесплатных чатов и раз в минуту проверяет, не вернулась ли Ollama.

## Настройки

Файл `.env` (шаблон — `.env.example`):

| Переменная | Назначение |
|---|---|
| `MAX_BOT_TOKEN` | Токен бота МАКС. Обязателен |
| `LLM_API_KEY` | `ollama` — включить нейросеть; пусто — работать без неё |
| `LLM_API_BASE` | Адрес Ollama, по умолчанию `http://localhost:11434/v1` |
| `LLM_MODEL` | Модель, по умолчанию `qwen2.5:3b-instruct` |
| `LLM_TIMEOUT` | Сколько секунд ждать ответа модели, по умолчанию 180 (скрипт установки ставит 300) |

Токен бота выдаёт @MasterBot в МАКС (команда `/create`).

## Запуск без Docker

```bash
pip install -r ../requirements.txt
cp .env.example .env        # впишите MAX_BOT_TOKEN
python vektor_znaniy_max_bot.py
```

Для ответов нейросети установите Ollama и скачайте модель: `ollama pull qwen2.5:3b-instruct`.

Проверка всех сценариев без сети и токена: `python tests/smoke_test.py`.

## Устройство кода

| Файл | Что внутри |
|---|---|
| `vektor_znaniy_max_bot.py` | Запуск, сценарии диалога, одно активное меню, обработка ошибок |
| `prompts.py` | Библиотеки промтов учителя и ученика, шаблоны теста, проверки и поиска, примеры, идеи дня — только данные |
| `texts.py` | Тексты сообщений |
| `keyboards.py` | Кнопки: ряды собираются в одно меню |
| `materials.py` | Чтение файлов, разбиение на абзацы, поиск, тест по материалу, быстрая проверка ответа |
| `formatting.py` | Markdown и LaTeX из ответа модели → оформление МАКС |
| `exporter.py` | .docx с эмблемой и колонтитулами, бланк теста, ключ таблицей |
| `llm_client.py` | Запросы к Ollama, проверка доступности модели, оценка времени ожидания |
| `assets/logo.png` | Эмблема для документов |
| `tests/smoke_test.py` | Более 100 проверок всех сценариев через диспетчер maxapi с подменой API МАКС и Ollama |

Новый сценарий добавляется записью в `prompts.py`: название, текст промта с полями в `{фигурных скобках}`, список полей и, если нужно, свои вопросы к ним (`"questions"`). Кнопка, вопросы пользователю и сборка промта появятся сами, обработчики менять не нужно.

## Требования и данные

- **ФГОС.** Промты для учителя построены по классам, предметам и типам уроков: цели урока (предметные, метапредметные, личностные), УУД, задания разного уровня сложности. В пилоте прежних ботов команды (24 педагога и 56 учеников) 94% материалов прошли экспертную проверку на соответствие ФГОС.
- **152-ФЗ.** Бот не спрашивает ФИО, оценки и другие персональные данные учеников. Базы данных нет: роль, избранное, история вопросов и загруженный материал живут только в памяти текущей сессии. Материал удаляется через 30 минут или по `/start`, остальное — по `/start`. На диск ничего не записывается. Статистика `/stats` — только анонимные счётчики.
- **Содержание.** Промты исключают материалы 18+ и не нарушают права третьих лиц (п. 9.2–9.4 правил хакатона «Идея фикс»).
- **Прозрачность.** Перед ответом нейросети бот пишет «Готовлю ответ…» с примерным временем, под тестом от нейросети — напоминание проверить ключ. Без нейросети бот показывает промт целиком, его можно поправить перед отправкой в чат.
